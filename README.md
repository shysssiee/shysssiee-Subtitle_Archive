# ShySssiee 影音紀錄／Podcast 網站安裝包 v1.4.3

## v1.4.3 介面修正版（2026-09-29）

本段為追加說明，舊版安裝、操作、備份與 GitHub Pages 教學均保留在下方，沒有覆蓋。

- 頂部導覽列改為「首頁｜影音紀錄｜Podcast｜POP Live｜關於我｜問題回報｜深淺模式」，原本標題下方的重複切換列已移除。
- Podcast 團體改用與影音紀錄一致的「團體專欄」圓角按鈕；選擇團體後，才會啟用該團成員選單。
- Podcast 改用粉淺黃、香草奶油黃與暖白色系，並新增同系列可愛耳機主視覺 `static/podcast-hero.webp`。
- 私密文章集中到「POP Live」。匯出 GitHub Pages 時輸入至少 8 個字元的共用密碼，訪客點選 POP Live 後需先解鎖。密碼只暫存於目前瀏覽器分頁，關閉分頁後即失效。這是 GitHub Pages 的前端加密保護；日後遷移正式後端時，再升級為伺服器權限驗證。
- 播放字幕工具列分為三個圓角區塊：「語言｜字幕字級｜劇院模式」。字幕預設 12pt，最高 16pt；桌面、平板、Android 與 iPhone／iPad 同步調整。
- 前台與後台分頁均改為圓角按鈕，支援頁碼、上一頁、下一頁，以及輸入頁數後按 Enter／前往跳頁。
- 深色模式重新補齊標題、內文、表單、播放器、字幕、逐字稿、警示、分頁與後台表格的對比色。
- 問題回報設定頁新增表單收件服務說明：GitHub Pages 不能直接寄信，需使用 Formspree、Web3Forms 等服務取得 HTTPS Endpoint，再由服務轉寄到管理員 Email。

匯出後請連同新增的 `pop-live/` 與 `static/podcast-hero.webp` 一起上傳；最簡單的方式仍是將匯出 ZIP 解壓後的全部內容完整覆蓋到 GitHub 儲存庫。

這是粉絲自發整理的影音紀錄與 Podcast 閱讀站。前台、後台都會依電腦、平板與手機螢幕調整版面。每場有獨立網址，使用妳貼上的 YouTube 網址播放，並顯示韓文與繁中 SRT／SBV 逐字稿。

> 「聲音收藏室」等名稱全是示意文案。網站名稱、標語、區塊標題、配色與字級都可在後台改。後台只在妳的電腦上啟動；從後台下載「公開網站 ZIP」即可將前台放到 GitHub Pages。更新時需重新匯出並上傳。

## 1. 安裝與啟動

需要 **Python 3.10 或更新版**。不需要安裝 pip 套件，也不需要 PHP、Node.js 或 MySQL。先將 ZIP 完整解壓，請勿在壓縮檔內直接執行。

**Windows：**雙擊 `start-windows.bat`。啟動檔會先確認壓縮包已解壓、Python 版本與後台密碼是否設定。v1.0.3 的批次檔使用 Windows 標準換行與英文診斷訊息，避免批次指令在部分 Windows 命令提示字元中被拆開。第一次會請妳在黑色視窗設定至少 12 個字元的後台密碼；輸入時不會顯示字元。啟動後在瀏覽器開啟：

- 前台：<http://127.0.0.1:8776/>
- 後台：<http://127.0.0.1:8776/admin>

如果雙擊後找不到 Python，請先安裝 Python 3.10+，安裝時勾選「Add Python to PATH」，再執行一次。

若 Windows 視窗仍很快關閉，可從解壓後的 `voice-archive` 資料夾，在檔案總管的網址列輸入 `cmd` 並按 Enter，再在命令視窗輸入 `start-windows.bat`。視窗會留下錯誤訊息，方便截圖回報。不要直接從 ZIP 預覽視窗中執行 `.bat`。

**macOS／Linux：**在此資料夾執行 `sh start-mac-linux.sh`。也可手動執行：

```bash
python3 app.py init   # 第一次設定密碼；之後不用重跑
python3 app.py serve
```

關閉命令列視窗或按 `Ctrl+C` 會停止本機網站。資料保存在 `data/archive.sqlite3`，停止程式不會刪除資料。

## 2. 第一次登入

開啟 `/admin`，輸入第一次啟動時設定的密碼。後台有影音紀錄／Podcast 內容管理、資料管理與網站管理。文章列表顯示總數及首次發文時間，可依標題、團體、分類和成員搜尋／篩選，每頁 10 篇。請妥善保管密碼；如需更換，在伺服器上執行 `python3 app.py init`，這會重設密碼並讓舊登入工作階段失效，不會刪除文章。

## 3. 新增一篇語音直播

1. 先把該場語音上傳到妳的 YouTube，建議影片畫面使用靜態節目封面。確認影片允許嵌入。
2. 全新安裝時，團體與分類都留空。先到後台自行新增，也可以不選。按「新增影音紀錄」或「新增 Podcast」，填文章標題、成員、**原直播日期**及簡介。成員欄輸入名字後按 Enter 或逗號成為獨立標籤；選定團體時會建議該團已用過的成員名稱。Podcast 編輯器另有 WE GO-6 五位成員的快速標籤。
3. 貼上 YouTube 的 `watch?v=...`、`youtu.be/...`、`live/...`、`shorts/...` 或 `embed/...` 網址。網址不是音檔下載連結；網站保留真正可見的 YouTube 嵌入播放器。
4. 上傳 UTF-8 編碼的韓文和繁中 `.srt` 或 `.sbv`；也可以直接貼在文字框。**上傳檔案會取代同一欄的文字框內容**。兩份字幕盡量使用相同時間軸。若時間差超過四秒，頁面會按字幕順序嘗試對齊，發布前請預覽核對。
5. 可上傳一張 **2 MB 以下的 PNG／JPG／WebP 文章縮圖**，用於首頁卡片、文章播放器載入前的畫面與社群分享。縮圖會存入本機資料庫，資料庫備份也包含它；公開網站 ZIP 則會匯出成 `static/covers/` 圖片。未上傳時使用預設圖。可在編輯頁移除或換圖。舊版已填的圖片網址資料仍會保留顯示，直到妳上傳新圖。請自行使用有權分享的圖片。
6. 設為「儲存草稿」後按儲存，再點文章的「預覽這篇文章」。確認沒問題，改為「公開發布」並儲存，**在確認視窗按「確定」**才會發布。首次發布時間會記錄為台灣時間，之後編輯不會重設。公開頁的網址是 `/podcast/妳設定的網址尾段`。

逐字稿可用「雙語／韓文／繁中」切換、調整文字大小與字幕時間偏移。字幕比聲音早出現時，偏移填正數；反之填負數。按某段時間可讓已載入的 YouTube 播放器跳到對應位置。播放器採點擊後載入，讓訪客剛進站時不必下載 YouTube 播放程式。場次列表每頁顯示 20 篇，可切換下一頁。

### SRT 範例

```srt
1
00:00:03,000 --> 00:00:06,000
안녕하세요 여러분

2
00:00:06,000 --> 00:00:09,000
오늘도 만나서 반가워요
```

繁中 SRT 同樣格式，使用對應時間軸與繁中內容。

### SBV 範例

```text
0:00:03.000,0:00:06.000
안녕하세요 여러분

0:00:06.000,0:00:09.000
오늘도 만나서 반가워요
```

逐字稿預設收合；點「展開雙語逐字稿」後在固定高度的區域內捲動。勾選「自動跟隨播放」會捲到目前的句子，取消勾選可自由捲動。播放中的繁中字幕在上、韓文在下，分兩層置中顯示。後台保留字幕原文，可繼續修改；SRT、SBV 都能解析時間軸。

### 單篇頁面的播放、字幕與分享

- 影片下方的控制列可播放／暫停、前後跳 10 秒、調整速度及拖動進度條，也顯示目前時間與總長。影片資訊載入前，總長暫顯示 `--:--`；速度以 YouTube 支援為準。原始影片連結改為獨立按鍵。
- 雙語字幕框隨播放時間顯示當句；完整逐字稿仍可捲動，點句子可跳到該時間。手機往下滑離開播放器時，底部出現**不透明**的影片、字幕與控制區；滑回時收起。影片本身仍維持 YouTube 規定的最小可見尺寸。
- 切換分頁、瀏覽器進入背景或離開頁面時會暫停；回來後要自行按播放。若手機瀏覽器限制首次程式播放，可直接點可見的 YouTube 播放器繼續。
- 文章可分享到 Threads、Facebook、LINE、X，也可複製網址。五星「影片翻譯評分」只存於讀者自己的瀏覽器，不顯示全站平均或人數。
- 分享按鈕為圖示，滑鼠停留會顯示名稱，鍵盤與輔助工具可讀到平台名稱。分享預覽優先使用上傳的文章縮圖；舊文章的 HTTPS 封面網址次之，最後用內附預設圖。不同平台可能快取舊縮圖。
- 播放字幕下有影片來源、AI 輔助整理及翻譯可能有誤的提示；問題回報連結可在後台設定。
- v1.4.3 可切換「劇院模式」，影片與正在播放字幕會一起放大；劇院按鍵、字幕語言與字級控制收在同一個字幕控制框，按右上關閉、再次按劇院鍵或鍵盤 Esc 即可退出。播放區依序為「影片 → 緊貼影片的字幕帶 → 播放控制」，字幕預設繁中，可切換韓文或雙語（繁中在上）；字級預設 12pt。

## 4. 修改文章、草稿與分享網址

- 後台首頁點文章右側「編輯」。可修改標題、團體、日期、YouTube 網址、兩份 SRT、筆記與狀態，再按「儲存文章」。
- 「草稿」不會出現在公開列表，也不能由訪客網址直接瀏覽。登入後可按「預覽這篇文章」。
- 把已公開文章改回草稿，相當於取消發布；原網址會暫時找不到文章。再改回公開後可沿用原網址。
- 公開後修改文章標題，網址尾段會保持不變，已分享的網址不會因改標題而失效。請在**首次公開前**檢查網址尾段。若留空，系統會產生 `voice-xxxxxxxx`。
- 後台文章列表及編輯頁均可刪除文章。刪除前會跳出確認視窗，且伺服器要求再次確認欄位。後台無法直接復原，請先下載備份；若事前有備份，仍可透過還原資料庫找回。已上傳 GitHub 的舊文章檔不會自動刪除，需手動移除。

## 5. 團體、文字和外觀設定

**團體、成員與分類管理：**新安裝的團體與分類留空，可從後台自行新增或更改名稱。「成員管理」可設定所屬團體、文章使用的篩選值、前台顯示名稱、排列順序及是否顯示，也可二次確認後刪除。文章編輯器與 Podcast 首頁選單會同步更新，升級不會刪除舊團體或文章。

**網站管理：**v1.4.3 將設定拆成「網站文字與外觀」「首頁區塊」「識別與字體」「關於我」「問題回報設定」。關於我可填 Threads、Instagram、YouTube 與聯絡信箱；首頁可調整區塊、Podcast 名稱與簡介，並決定是否在列表顯示私密文章卡片。版本號由安裝包自動附在頁尾。

瀏覽器分頁標題在全站固定使用「網站名稱｜網站副標題」，不會因切換 Podcast、文章、關於我或問題回報而改成頁面名稱。

**Podcast 團體與成員：**Podcast 首頁使用「團體＋成員」兩個下拉選單。選好團體後，第二個選單才列出該團成員，避免首頁堆疊大量按鈕。資料來源是後台「成員管理」，日後新增其他團體不需要修改程式。WE GO-6 的預設順序為 Wooyeon／鄭羽然、Xiu／車時雨、Taegang／朱泰岡、Zero／傑羅李、Kuta／蒼井 空汰；第一次升級會建立到後台，之後可自行修改、隱藏或刪除。

**問題回報：**先向妳選擇的表單收件服務取得 HTTPS 表單送出網址，再貼到「問題回報設定」。讀者只需選問題類型、填說明；暱稱與影片時間點選填，不要求 Email 或電話。從文章內的問題回報連結前往時，頁面會自動帶入文章網址。第三方服務的保存與寄信規則仍依該服務設定。

頁尾製作署名可自行修改；版本號（目前為 v1.4.3）由安裝包自動加在署名後方，首頁與每篇文章會同步顯示。

**深色／淺色：**前台右上方可切換，選擇儲存在各讀者的瀏覽器。問題回報可填妳自己的表單 HTTPS 網址；未填時會嘗試開啟讀者的電子郵件程式，建議發布前填好正式表單網址。首頁圖採壓縮 WebP；電腦版文章卡片兩欄、手機版單欄。

**分享網站網址：**請先在後台「網站文字與外觀」填入正式的 GitHub Pages 首頁完整網址，例如 `https://帳號.github.io/儲存庫名稱/`，再匯出公開 ZIP。社群分享縮圖需要此網址。未設定時，匯出頁會提醒妳。

**源樣黑體：**頁面優先使用裝置已安裝的「源樣黑體」，未安裝時使用系統繁中黑體以減少初次下載流量。若妳之後有自行託管的合法網頁字體樣式表，可在後台填 HTTPS 字體樣式表網址；請先確認該 CSS 定義的字體家族名稱及跨網域載入可用。第一版未內含大型中文字體檔，避免單次進站下載數 MB。

## 6. 備份、還原與版本更新

- 後台點「下載備份」可取得一致性的 SQLite 資料庫備份。備份檔含文章、字幕、**已上傳的縮圖**、設定及管理密碼雜湊，請妥善保管。
- 還原前先**停止網站**，把備份檔命名為 `archive.sqlite3` 放進 `data/`，覆蓋舊檔；若有 `archive.sqlite3-wal`、`archive.sqlite3-shm`，在停止網站後移走舊檔，避免混用。重新啟動後用備份時的密碼登入。
- 更新安裝包時，先在後台下載備份，關閉執行網站的命令視窗。將新版 ZIP 解壓到另一個資料夾，把**舊版 `voice-archive/data/` 整個資料夾複製到新版 `voice-archive/`，取代新版空的 `data/`**，再雙擊新版 `start-windows.bat`。不要重新執行 `app.py init`，原密碼、文章及設定會保留。確認可登入且文章仍在後，才刪除舊版資料夾。
- README 持續維護：舊版仍適用的步驟保留；新增功能補入對應章節，並在下方版本紀錄說明差異與必要升級動作。不要以簡略新檔覆蓋舊說明。

## 7. 匯出並發布到 GitHub Pages

1. 在本機後台將文章設為「公開發布」「私密文章」或「草稿」。草稿不會匯出；私密文章會進入公開 ZIP，但內容以共用密碼加密。
2. 先到「網站文字與外觀」設定正式 GitHub Pages 首頁網址，再到「匯出 GitHub Pages」。若有私密文章，本次匯出需輸入至少 8 個字元的共用密碼；密碼不會寫入資料庫。這份 ZIP **不是私人資料庫備份**。
3. 解壓公開網站 ZIP。將 ZIP **裡面的** `index.html`、`about/`、`report/`、`episode/`、`podcast/`、`static/` 與 `.nojekyll` 上傳到儲存庫根目錄。不要上傳 ZIP 本身、`app.py`、`data/`、`archive.sqlite3` 或備份檔。
4. 到儲存庫 **Settings → Pages** 設定 `main` 分支與 `/ (root)` 發布來源。等待 GitHub 顯示網址，再檢查首頁、文章、字幕與 YouTube 播放。
5. 每次更新：在本機後台儲存 → 重新下載公開網站 ZIP → 解壓並覆蓋 GitHub 上的公開檔案。若要移除文章或網址變更，請在 GitHub 同步刪除舊的 `episode/舊網址/` 與相容用 `podcast/舊網址/`；匯出不會自動刪除遠端舊檔。

每篇新網址是 `https://帳號.github.io/儲存庫名稱/episode/文章網址尾段/`；舊的 `/podcast/文章網址尾段/` 會轉往新網址。影音紀錄首頁為 `/`，Podcast 獨立頁為 `/podcast/`。兩頁的搜尋、篩選與每頁 10 篇分頁均在訪客瀏覽器中運作。**公開站沒有後台登入**；妳仍在自己的電腦開 `http://127.0.0.1:8776/admin` 編輯。

### 私密文章的重要限制

- 這是「靜態頁面內容加密」，不是會員系統，也不會改變 YouTube 影片本身的觀看權限。
- 密碼不保存在瀏覽器；重新整理、關閉／離開頁面後再次進入，都要重新輸入。
- 共用密碼可轉傳。請勿把此功能視為高機密檔案保管；變更密碼時要重新匯出並完整覆蓋 GitHub Pages。
- 若首頁顯示私密卡片，訪客仍會看見卡片標題；可在「首頁區塊」關閉顯示。私密內頁的原始 HTML 與社群標籤使用通用名稱，不直接公開文章標題、摘要或字幕。

### 本機與其他主機

本機預設只綁定 `127.0.0.1`，其他人不能直接開啟妳的本機網址。Podcast 預設用 **8776**，與 SKINZ v3 使用的 8765 分開，兩站可同時開啟。若之後部署到線上，需有持續運行 Python 的主機、HTTPS、反向代理、持久化 `data/` 及定期備份，並設定 `VOICE_COOKIE_SECURE=1`。可用 `python3 app.py serve --host 127.0.0.1 --port 8776` 由反向代理轉送；勿直接把本機 HTTP 服務暴露在公開網路。**GitHub Pages 只能放靜態檔，不能直接執行此 Python 後台或即時更新資料庫。**

首頁不預載每一場的 YouTube 播放器。進入文章後也要先點「載入 YouTube 播放器」，才會連到 YouTube。本站圖片使用延遲載入；較輕的字體備援與少量動畫有利手機流暢閱讀。

## 8. 常見問題

**播放器顯示「無法播放這部影片」？** YouTube 的「公開」與「不公開列出」影片都能透過網址觀看，草稿也能從後台預覽。先點「在 YouTube 觀看原始影片」：若原站也不能播放，檢查網址與影片狀態；若原站可播放而本站不能，檢查「允許嵌入」以及年齡、版權或地區限制。v1.0.5 調整了嵌入方式；若個別影片仍無法播放，請提供該影片網址及錯誤畫面。

**字幕不同步？** 先比對韓文與繁中 SRT 的起始時間、句數及 YouTube 影片是否剪過片頭。修改 SRT 並重新儲存文章。

**文章沒有出現在首頁？** 檢查狀態是不是「公開發布」，或目前首頁是否選了某個團體篩選。

**想使用其他團體或分類？** 到「團體管理」或「分類管理」新增後，再回文章編輯畫面選取。

**忘了管理密碼？** 有本機檔案存取權的站長可在伺服器執行 `python3 app.py init` 重新設定；文章不受影響。

**密碼正確卻回到登入頁？** 使用 v1.0.4 以上，登入工作階段會先寫入資料庫再轉頁。若頁面顯示「瀏覽器未保留登入狀態」，請在瀏覽器允許 `127.0.0.1` 的 Cookie，並統一使用 <http://127.0.0.1:8776/admin>，不要在 `localhost` 與 `127.0.0.1` 之間切換。更新時保留 `data/`，原密碼可繼續使用。

**Windows 雙擊後視窗一閃就關？** 先確認雙擊的是新解壓資料夾裡的 `start-windows.bat`，而非舊版資料夾。v1.0.3 的 `start-windows.bat` 會在結束前停留並提示缺少 Python、未完整解壓或連接埠被占用等原因。若仍出錯，使用上面的 `cmd` 方式執行並截圖。

**SKINZ v3 正在執行，Podcast 開不起來？** v1.0.0／v1.0.1 也使用 8765，會與 SKINZ v3 衝突。請使用 v1.0.2，Podcast 改用 8776；前台網址是 <http://127.0.0.1:8776/>。兩個命令視窗都保持開啟即可。

## 10. v1.4.0 首頁與字幕更新包的新增操作

- **關於我**：後台「網站文字與外觀」可修改導覽名稱與內文。文字換行會分段顯示，匯出後產生 `about/index.html`。
- **Logo**：同一設定頁可上傳 PNG／JPG／WebP（2 MB 以下），尺寸可設 24～80px。上傳圖片優先於圖片網址；取消圖片可勾「移除已上傳 Logo」，若仍填有圖片網址則改用該網址。公開匯出會把 Logo 存成共用圖片，避免每篇重複內嵌圖片資料。
- **首頁**：團體專欄由團體管理自動產生；可按直播日期由新至舊／由舊至新排序，每頁最多 20 篇。後台文章管理仍維持每頁 10 篇。卡片顯示直播日期、團體、分類及成員。
- **隨機推薦**：最多兩篇，按「換一批」重新挑選。配合目前團體篩選；有三篇以上時避開最新一篇。可在外觀設定關閉推薦區，標題亦可修改。
- **縮圖與分享**：文章編輯的「上傳文章縮圖」同時用於首頁和社群預覽。建議使用清楚的橫式 JPG／PNG，例如 1200×630。未上傳時會沿用舊圖片網址，或使用包內預設分享圖。正式首頁網址必須包含 GitHub 儲存庫路徑；不要填單篇文章網址。
- **分享圖檢查順序**：重新匯出並上傳整份公開檔案 → 等待 GitHub Pages 發布 → 在瀏覽器開啟文章與 `static/covers/` 的對應圖片 → 再重新分享。此包補齊 Open Graph／Twitter 圖片資訊，上傳圖片更換時也會更新圖片網址的識別。既有 Threads／Facebook 貼文可能仍沿用平台快取；本機測試無法保證平台立即更新縮圖。
- **更新替換**：請依第 6 節保留整個 `data/` 資料夾；重新匯出時務必一併更新新增的 `about/`，以及 `index.html`、`podcast/`、`static/`。版本文字保持 v1.4.0，資源快取識別已更新。
