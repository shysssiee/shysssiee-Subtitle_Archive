ShySssiee 網站 v1.4.3 介面修正版

一、替換前
1. 關閉目前執行中的網站黑色視窗。
2. 複製原網站資料夾中的 data 資料夾，另外保存一份。

二、建議替換方式
1. 解壓縮本修正版。
2. 將解壓後的 app.py、static、README.md、更新內容.md、start-windows.bat、start-mac-linux.sh 複製到原網站資料夾。
3. Windows 詢問是否取代檔案時，選擇「取代目的地中的檔案」。
4. 不要刪除或覆蓋原本的 data 資料夾；文章、設定與後台密碼都保存在裡面。
5. 重新雙擊 start-windows.bat。

三、更新 GitHub Pages
1. 在本機後台確認網站內容。
2. 進入「匯出 GitHub Pages」。
3. 若有 POP Live 私密文章，輸入至少 8 個字元的共用密碼。
4. 下載匯出 ZIP 並解壓縮。
5. 將解壓後全部檔案上傳到 GitHub 儲存庫根目錄，包含新增的 pop-live 資料夾與 static/podcast-hero.webp。

四、瀏覽器仍顯示舊畫面
請按 Ctrl＋F5 強制重新整理；手機可關閉該網站分頁後重新開啟。
